Seletores CSS

Aplicando CSS em diferentes partes do HTML

  1. O seletor de elemento seleciona os elementos com base no nome da sua tag HTML.
  2. Os seletores de classe selecionam os elementos com base no valor do atributo class.
  3. Os seletores de ID selecionam os elementos com base no valor do atributo id.
  4. Os seletores de atributo selecionam os elementos com base em seus atributos e respectivos valores.
  5. O seletor universal seleciona todos os elementos da página.
